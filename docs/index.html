项目简介

这是一个面向课程设计与简历的快递驿站管理系统。系统采用纯 C 语言实现，用户可注册、登录、寄件、取件、 查看包裹轨迹与站内消息；管理员可完成包裹入库、出库、多条件查询、库存盘点、用户注销和操作日志审计。 启动时会自动模拟“运输中 → 已到站”和“滞留超时”的业务状态流转。

功能模块

用户端

  • 注册 / 登录 / 注销
  • 寄件与运费明细
  • 取件码取件 / 代取
  • 包裹轨迹时间线
  • 站内消息通知

管理端

  • 包裹入库 / 出库
  • 按用户、单号、运输方式查询
  • 库存列表与系统概览
  • 注销用户
  • 操作日志查看

工程能力

  • 文本化持久层
  • 模块化分层架构
  • 健壮输入校验
  • 自动演示数据
  • 单文件 / 模块化双版本
